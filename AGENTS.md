# LimeLeaf Visual Theme

## Brand Direction
- Keep the main visual identity bright, fresh, and green.
- Use `--brand-primary` for major green sections and primary actions.
- Use `--brand-accent` for cards, highlights, badges, and promotional accents.
- Use `--brand-primary-dark` for text and controls placed on bright green surfaces.
- Use `--brand-surface` only for neutral supporting sections, not as the dominant homepage color.
- Keep white for content surfaces when lime would reduce readability.

## Design Rules
- New homepage sections should default to green or lime before introducing neutral colors.
- Do not replace an existing green section with gray, beige, or white unless the user explicitly requests it.
- Keep promotional areas energetic with high-saturation greens and strong contrast.
- Prefer the shared CSS variables in `src/styles.css` over new hardcoded brand colors.
- Preserve WCAG-readable text contrast on every green background.
